DENOBLETECH QA PORTFOLIO — LOCAL WEBSITE

This is a static HTML/CSS/JavaScript website adapted from the supplied reference portfolio files.
The original dark visual system, section order, cards, spacing, navigation style, and interactions are retained as closely as possible while the text and evidence are changed.

PREVIEW ON WINDOWS
1. Extract this ZIP into a folder.
2. Open the folder.
3. Double-click index.html to preview it in Chrome.
   (Google Fonts requires an internet connection; the rest of the site is local.)

PUBLISH WITHOUT GITHUB
You can deploy the folder with a static hosting provider such as Netlify by uploading the site folder through its manual deploy flow. Hosting provider account/plan requirements may change.
